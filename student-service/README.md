# student-service

Студенты, учебные группы и избранные курсы.

Профили студентов (ФИО, телефон, дата рождения, статус, группа), учебные группы и список избранных курсов студента.

- Порт: `8081`
- Таблицы в `uspeh_db`: `groups`, `students`, `favorites`

## Эндпоинты

| Метод | Путь | Описание | Ответ |
|---|---|---|---|
| GET | `/students` | Список всех студентов | `200` |
| GET | `/students/{id}` | Студент по id | `200`, `404` |
| POST | `/students` | Создать студента | `201`, `400`, `404` (нет группы), `409` (userId занят) |
| PUT | `/students/{id}` | Обновить студента целиком | `200`, `400`, `404`, `409` |
| DELETE | `/students/{id}` | Удалить студента вместе с его избранным | `204`, `404` |

Через api-gateway: `http://localhost:8080/api/students`. Swagger: `http://localhost:8081/swagger-ui.html` или общий на gateway — `http://localhost:8080/swagger-ui.html`.

Тело запроса POST/PUT (`StudentRequest`):

```json
{
  "firstName": "Алексей",
  "lastName": "Кузнецов",
  "phone": "+79161234567",
  "birthDate": "2005-03-14",
  "groupId": 1,
  "userId": null,
  "status": "ACTIVE"
}
```

Обязательны `firstName` и `lastName`. `phone` — 10–15 цифр, можно с `+`; `birthDate` — в прошлом;
`status` по умолчанию `ACTIVE`. PUT заменяет все поля: что не передано, станет пустым.
Ошибки возвращаются в формате Problem Details, при ошибке валидации — с полем `errors` по каждому полю.
